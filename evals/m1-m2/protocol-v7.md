# M1/M2 regression protocol v7

V7 retains v6's unchanged 30-case corpus, repository pins, CLI/model pins,
calibrated binary predicates, isolated Claude judge, complete hook capture,
denominators, and milestone thresholds. Freeze the candidate commit and binary
checksums before the first scored invocation; every result records that commit.
This is a disclosed regression, not an independent holdout.

V6 completed all 30 pairs with three invalid comparisons. Useful application
was 7/15 and delivered-claim quality 21/29, below their targets. All failures,
unknown repeated-investigation counts, and the original malformed judge attempt
remain preserved in the v6 evidence.

The corrected product canonicalizes project scope at server ingress, derives
branch/session defaults from the attributed session, restores legacy project
rows in automatic context, and carries supersede targets through the spool.
Unsupported local observation IDs are refused rather than silently discarded.
Capture instructions preserve user decisions and failure identifiers even when
source already agrees and avoid unrelated source summaries.

Use a fresh database and short protected output path. Run every case once;
capacity scheduling may separate case batches without changing within-case arm
order or inputs. Retain failed agent phases as invalid comparisons. A failed or
malformed judge process may be retried in a fresh isolated process with its
original attempt retained; never replace a valid judgment. Unknown judgments,
incomplete inventories, or failed comparisons block the affected gate.

The same calibrated judge profile and rubric apply. Original Laya, Astra, and
Claude calibration/results remain preserved. Shared model-family limitations,
unverified Codex provider identity, and instrumented latency remain disclosed.
Do not remove unsupported seeded claims from delivery-quality denominators
because an agent rejected them; harm and claim support are separate predicates.

Thresholds remain 80% useful application, 90% delivered claims both relevant
and supported, zero privacy leaks/high-impact harmful advice, 20% median fewer
repeated investigation steps on eligible control pairs, and treatment completion
no worse than control. Empty or unresolved denominators are never a pass.
